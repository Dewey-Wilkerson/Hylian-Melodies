# Contributing

Hylian Melodies is a personal-use static recompilation of a game the user owns. The repository holds **source code
and documentation only**. Read this before committing anything.

## Content rules

The repository, its history, commit messages, tests, docs and issue text must never contain:

- game code: the original binaries, disassembly or decompilation, or **C generated by the lifter**;
- game assets: RomFS files, textures, audio, fonts, shaders, metadata, strings dumped from the game;
- Nintendo/Switch firmware content, system fonts, or any keys (`prod.keys`, `title.keys`, title keys from tickets,
  derived keys, or hashes of keys);
- anything copied out of an XCI, NSP, NCA, NSO, NRO, NPDM, NACP or ticket.

Allowed: our own code and docs, and **facts** that are not expressive content: file sizes, SHA-256 hashes of the
official files, build IDs, title IDs, version numbers, counts.

Game-specific patches are stored as **logic that locates its site at install time** from the user's own files
(instruction or structure patterns, keyed by build ID), never as copied bytes, symbol names, function bodies or
string tables from the game. No game-derived symbol names anywhere (code, docs, commits, tests). When unsure whether
something is a fact or expressive content, don't commit it: write the question in `docs/OPEN-QUESTIONS.md`.

Mechanical guards:

- `.gitignore` covers every game-derived directory and container type.
- `tools/check_content.py` refuses forbidden types, files over 512 KiB, binaries, high-entropy blobs, key-looking hex
  strings, game-data paths and the generator's marker. The pre-commit hook runs it on every commit; enable it once
  per clone with `git config core.hooksPath .githooks`. `tests/test_check_content.py` proves the hook works.
- Game data lives outside the tree (`~/.cache/hylian-melodies/`, the PKGBUILD's `$srcdir`).
- Never print, log or paste the contents of a keys file or a title key. Logs may say "keys file found, N entries".
  hactool prints key values in its warnings, so its output is always filtered (`installer/hactool.py`).

## Third-party code

Before copying or adapting code from another project: read its license, then add a row to
`THIRD_PARTY_NOTICES.md` in the same commit. MIT, BSD, ISC, zlib and Apache-2.0 only. GPL/AGPL code (SwitchRECOMP,
its Vulkan renderer, Unicorn, yuzu and friends) may be read for behaviour but not copied or linked without the
owner's approval. The project's own code is MIT.

## Publishing

Nothing is pushed, released or published without the owner's explicit approval. No remote is configured.

## Style

Fast to get correct and consistent with the reference projects. Commits are small and local, plain-sentence
messages, no game-derived text. Run `python3 -m unittest discover -s tests` before committing.
