# Environment variables

Generated by `python3 -m installer.options > docs/env-vars.md` from `installer/options.py`; a test
checks this list against every `getenv`/`ENV("HM_...")` in `runtime/`. Edit the registry, not this file.

The installer writes the player's choices into the game's settings file,
`~/.local/share/hylian-melodies/hylian-melodies.ini` (the same file the in-game menu saves). Each
setting's variable, when set in the environment, wins over the file.

## Settings the installer asks about

- **Start in fullscreen** (`fullscreen = 0`): Borderless, at the desktop's resolution. F11 or Alt+Enter switches while playing, and the in-game menu (F1) has the same setting.
- **Graphics card** (`gpu = auto`; `HM_GPU`): Which graphics card draws the game, on a computer with more than one. Left on auto, the game takes the separate (faster) card when there is one. The number is the one in the log lines "[vk] gpu N: ...".

## Troubleshooting (off unless something is wrong)

- **Turn off frame pacing** (`frame_pacing = 0`; `HM_FRAME_PACING`): Lets the game run on its own limiter (about 61 pictures a second) instead of the console's steady 60. Try it if the picture stutters evenly; the beat may then drift against the picture. Also in the in-game menu.
- **Rebuild the shaders at every start** (`shader_cache = 0`; `HM_VK_NO_SPIRV_CACHE`): Ignores the saved shader cache. Try it once if the picture is wrong after a graphics driver update; starting takes longer.
- **Check graphics calls (Vulkan validation)** (`vk_validation = 1`; `HM_VK_VALIDATION`): Writes the graphics driver's complaints to the log, for a bug report. Needs the Vulkan validation layers installed; slower.
- **Log controller and keyboard input** (`log_input = 1`; `HM_LOG_INPUT`): Writes which buttons the game receives to the log, to find out why a controller or key does nothing.
- **Log audio timing** (`audio_stats = 10`; `HM_AUDIO_STATS`): Writes a line about the sound output every 10 seconds (rate, gaps, queue), for crackling or drifting sound.

## Set by the game for itself

- `HM_LOG_APPEND`: set when the game restarts itself: the new process appends to the same log
- `HM_REEXEC`: counts those restarts (the address range the game needs was taken)

## Read outside the game

- `HM_GAME_DIR`: the launcher too: the installed game instead of /opt/hylian-melodies (tests)
- `HM_SUPPORT_DIR`: the launcher: the support files instead of /usr/share/hylian-melodies-recomp (tests)
